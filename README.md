📘 Projeto: Quizz MAUI

Este projeto é um aplicativo de quiz desenvolvido com .NET MAUI, voltado para perguntas de múltipla escolha com interface amigável e interativa.

🧩 Funcionalidades

Exibição de perguntas com alternativas via RadioButton

Verificação de resposta correta ou incorreta

Interface estilizada com Border, sombras e cores personalizadas

Navegação entre páginas de perguntas.
